Сайтiк.

Первое, что нужно сделать, это запустить локалхост, и на нём запустить сайт. 
Лучше всего это делать через прогу XAMPP. Как это сделать?

1. качаем xampp
2. после установки, запускаем локалхост Apache
3. нажимаем в XAMPP open containing folder
4. находим каталог htdocs
5. именно ТУДА кидаем каталог с самим сайтом, который скачали в .зип архиве
6. заходим в браузер (желательно пока тестить сайт на ФурриЛисичке)
7. пишем в адресной строке "localhost/имя каталога с сайтом/MainPage.html"
8. если все сделано правильно, то у вас должен отобразиться сайт.
